# Production Area Inspection Checklist

เว็บฟอร์มกรอกแบบตรวจพื้นที่ผลิต (Production Area Inspection Checklist)

## ใช้งาน

1. กรอกข้อมูลสถานที่ ผู้ตรวจ และวันที่
2. เดินตรวจแล้วเลือกผลแต่ละรายการ: **ผ่าน / ไม่ผ่าน / N/A**
3. ถ้าไม่ผ่าน ให้ระบุความเสี่ยงและบันทึกการแก้ไข
4. เพิ่มงานค้างก่อนการตรวจครั้งถัดไป (ถ้ามี)
5. กด **ส่งออก Excel** เพื่อดาวน์โหลดไฟล์ `.xlsx`

ฉบับร่างถูกบันทึกอัตโนมัติในเบราว์เซอร์เครื่องนี้เท่านั้น

## หมวดที่ตรวจ

- ทางเดินและพื้น
- เครื่องจักร
- ไฟฟ้า
- สารเคมี
- ดับเพลิงและฉุกเฉิน
- PPE
- สภาพแวดล้อมงาน
- ความเป็นระเบียบ (5S)
- การขนส่งในพื้นที่
- สุขอนามัยพื้นที่ผลิต

## รันบนเครื่อง

```bash
npm install
npm run dev
```

เปิดที่พอร์ตที่เทอร์มินัลแสดง (ค่าเริ่มต้นของโปรเจกต์นี้ใช้พอร์ต `3457` เมื่อรันด้วยสคริปต์ด้านล่าง)

```bash
npm run dev -- --port 3457
```

สร้างเวอร์ชัน production:

```bash
npm run build
npm start -- --port 3457
```

## หมายเหตุ

ไฟล์ Excel ที่แนบตอนสร้างโปรเจกต์อ่านจากเครื่อง agent ไม่ได้ในตอนนั้น
ฟอร์มนี้จึงจัดรายการตามโครงสร้างมาตรฐานของ Production Area Inspection Checklist
(ผ่าน/ไม่ผ่าน/N/A, ความเสี่ยง, การแก้ไข, งานค้าง, ลงนาม)
หากต้องการให้รายการตรงกับไฟล์ต้นฉบับทุกข้อ ส่งไฟล์มาอีกครั้งแล้วจะปรับให้ตรงได้
